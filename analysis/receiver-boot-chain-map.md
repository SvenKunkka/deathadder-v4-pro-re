# 接收器启动主链静态图

原函数 `23026020` 顺序调用以下九个入口，不检查其返回值，最后返回 0。因此该函数返回 0 不能证明所有子系统初始化成功。依据是原始 Thumb 调用指令与已保存反编译；本图不是整链执行验证。

|2|`0E05BE4C`|RTC比较/回调调度|未接入|
|3|`23025848`|存储设备检查与两区挂载|本轮恢复|
|4|`23026F6C`|配置加载|已有恢复模块|
|5|`23025EE0`|GPIO与PWM相关初始化|未接入|
|6|`23026C58`|USB/事件相关对象注册|语义待进一步核对|
